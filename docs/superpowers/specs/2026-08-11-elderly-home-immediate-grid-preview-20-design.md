# 老年首页即时应用网格 Preview 20 设计

## 目标

让固定老年设备的首页应用入口在首屏出现后立即可读、可点，并在系统大字体下不裁剪应用名称。Preview 19 为短屏可达性将 `RecyclerView` 放进外层滚动容器并按全部内容测高；这会使应用多时失去回收、放大图标加载和内存消耗，也会破坏跨屏拖动。本版恢复单一可虚拟化的首页列表，同时修正应用卡片入场延时和固定高度。

## 用户体验

- 首页应用卡片绑定完成即保持完全可见，不淡入、不位移、不等待动画结束。
- 应用卡片使用自适应高度，并保留与图标缩放设置一致的最小高度；系统字体放大时卡片可以向下增长，完整显示最多两行名称。
- 首页只使用一个 `match_parent` 的可滚动 `RecyclerView`。天气、加载/错误状态和常用电话成为全跨两列的 header；应用入口保持两列并由 RecyclerView 按视口回收。
- 应用网格仍保持稳定图标尺寸和拖动排序；拖动只能在应用项间移动，不能越过 header。不改变电话、视频、可信联系人或 Root 行为。
- 离屏缓存卡片不是已回收卡片：图标加载在 detach 后继续，只有 recycle 才取消；图标比例变化会按新尺寸重载而不先闪回占位图。
- 拖拽中的手动 move 是唯一的视觉位置通知；结束提交只更新异步 differ 的内部快照。拖拽期间到达的新应用列表在提交后继续应用，不能被旧快照覆盖。
- 低性能模式继续缩小图标和阴影，但不改变可读性或点击语义。

## 设计约束

- 不引入新的定时器、服务、轮询、网络请求或 Root/BusyBox 命令。
- 不以 `maxLines=1`、缩小字体或截断文案掩盖布局问题。
- 不改变现有应用排序、入口顺序和拖动范围。
- 首屏验收以 `alpha=1`、`translationY=0`、卡片 `wrap_content`/最小高度，以及 `match_parent` RecyclerView/跨列 header 为可自动验证的契约。

## 验收

- Robolectric 首页 smoke 测试确认首屏已绑定的应用卡片没有 alpha/translation 动画残留。
- 资源/绑定测试确认应用卡片根和内容容器是 `wrap_content`，并有可缩放的最小高度；大字体文本仍允许两行。
- 首页 smoke 测试确认没有外层滚动容器，RecyclerView 自己滚动且为 `match_parent`；header 占满两列，应用项只占一列。
- 拖动回归确认 header 不能进入应用排序事务，应用内部排序仍使用其相对位置。
- 图标生命周期回归确认 detach 后完成的位图可用于缓存卡片，缩放后以新尺寸重载；拖拽回归确认每次移动只通知一次且并发列表刷新不丢失。
- 既有全部 JVM、Android 测试源编译、Debug APK 和未改变的 Root 回归矩阵通过。
- 没有真实 OnePlus 15 时，不宣称 ColorOS 16 的实际帧时延或功耗；这些仍是设备验收项。

## 非目标

本 Preview 不修改 KernelSU 模块、BusyBox、自动无障碍恢复、开机策略、拨号状态机或联系人数据。
