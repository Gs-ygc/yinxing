# 银杏 Root 健康预览 2

本版继续面向中国版一加 15、ColorOS 16、KernelSU Root 专机，新增可观测的 Root 健康状态和一次性修复入口。现有无障碍自动化仍是语义后端；Root 负责保活、无障碍服务恢复和桌面恢复，不替换节点树、手势和全局动作能力。

## 资产

- `yinxing-1.10.0-root-preview.2-debug.apk`：设置页包含“Root 专机状态”卡片的体验 APK。
- `yinxing-guard-1.10.0-root-preview.2.zip`：KernelSU 模块。
- `SHA256SUMS.txt`：两个文件的 SHA-256 校验值。

## 安装前注意

APK 使用当前构建机的 Debug 签名，不是正式发布私钥签名。若手机上的银杏来自其他签名，Android 可能拒绝覆盖安装；需要先备份联系人和设置，再决定是否清洁安装。KernelSU 模块可以单独升级，模块版本和 APK 版本应保持同一预览号。

本版只针对 Android 用户 0 的固定 Root 专机，不覆盖工作资料、系统分身或多用户空间。构建机没有连接目标一加 15，因此 ColorOS 16 的实际授权弹窗、开机时序和厂商后台策略必须以真机体验为准。

## 安装顺序

1. 安装 APK，至少启动一次，并确认银杏仍是默认桌面。
2. 在 KernelSU 管理器中安装 `yinxing-guard-1.10.0-root-preview.2.zip`，启用 `Yinxing Root Guard`。
3. 重启手机，等待系统进入桌面。
4. 打开银杏“家属设置”，点击“Root 专机状态”。只有打开这个面板时才会发起一次 Root 状态检查；普通启动和普通设置刷新不会请求 `su`。
5. 若状态显示“需要处理”，点击“立即修复并复查”。应用只调用模块的固定 `action.sh` 入口，完成后立即重新读取固定状态快照。

## 体验检查

1. 重启后确认银杏自动回到默认桌面，无需手动进入无障碍设置。
2. 在 Root 面板确认模块、守护进程、无障碍、Doze、清理助手和上次修复状态均显示正常。
3. 手动关闭银杏无障碍服务，等待最多一个守护周期，再点击 Root 面板检查；确认服务能够恢复。
4. 在 Root 面板执行一次“立即修复并复查”，确认状态刷新且不会反复抢占前台。
5. 没有 Root 或模块被禁用时，确认页面显示“Root 不可用”或“模块未安装”，原有权限页面仍可手动开启无障碍和悬浮窗。
6. 如果原本启用了 TalkBack 或其他无障碍服务，确认它们仍然保留；Root Guard 只管理银杏自己的服务。
7. 在 KernelSU 中禁用模块并重启，确认银杏回到原有手动无障碍流程。

## 安全边界

- APK 只允许通过 `su -c` 调用两个固定路径：模块 `bin/status.sh` 和 `action.sh`。
- 状态输出必须是严格的固定键值集合；命令失败、超时、输出过长或格式异常都显示为 Root 不可用，不会显示为健康。
- Root 面板不会提供任意命令输入，也不会修改系统分区、SELinux 规则或联系人数据。
- 修复操作不会循环重试；需要再次处理时由家属明确点击。

## 诊断与反馈

模块日志标签固定为 `YinxingGuard`，可在已授权终端查看：

```sh
su -c 'logcat -d -s YinxingGuard'
```

反馈问题时请提供 ColorOS 完整版本、KernelSU 管理器/内核版本、Root 面板显示的状态、复现步骤和相关日志。请先移除联系人、电话号码和令牌等个人信息。

## 回滚

1. 在 KernelSU 管理器中禁用或卸载 `Yinxing Root Guard`，然后重启。
2. 模块会在开机完成阶段撤销它自己添加的 Doze 白名单，并清理守护锁、PID、启动批次和修复结果状态；系统原有 Doze/无障碍设置不会被删除。若系统拒绝安装开机清理助手，卸载脚本会返回失败并保留所有权标记，不会静默报告成功；修复清理助手目标后可重试卸载。
3. 如果手机无法正常进入系统，使用 KernelSU 的模块救援方式禁用 `yinxing_guard` 后重启。
4. 需要回到纯手动流程时，在 Android 无障碍设置中按原流程启用银杏服务即可。
